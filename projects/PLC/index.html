設備控制平台（Virtual PLC）

CZ Virtual PLC 是一套針對 Czochralski 長晶製程打造的軟體 PLC 模擬與控制平台，位於 Plant Simulator 與 DCS 之間，負責固定掃描週期、I/O Image、安全聯鎖、順序控制、本地 PID 與版本化 Telemetry Contract。

Highlights

System Positioning

Virtual PLC 位於 Plant Simulator → CZ Virtual PLC → CZ DCS → CZ SPC 鏈路中，負責把模擬器 PV 轉換成 PLC Tag、I/O Image、品質碼、聯鎖狀態與不可變 DCS Snapshot。

Deterministic PLC Scan

每個 Scan Cycle 依序讀取 Plant tags、驗證 OPC UA 品質與新鮮度、更新 Input Image、執行安全聯鎖、推進製程順序、計算本地控制輸出、寫入 Output Image 並發布 DCS Snapshot。

OPC UA Plant Adapter

PLC Runtime 透過 OPC UA 讀取獨立 Plant Simulator，而不是自行生成主要製程 PV；可設定 runtime enable、scan interval、endpoint、namespace 與 Plant Simulator HTTP API URL。

Fail-safe Boundary

當 Plant Simulator 逾時、OPC UA Quality 不良、PLC 停止、製程狀態不允許或外部來源失聯時，控制輸出會歸零或進入安全值，避免 DCS 指令繞過 PLC 安全聯鎖。

CZ Sequence Control

順序控制涵蓋 MELT、STABILIZE、SEED、NECK、CROWN、BODY、TAIL，Virtual PLC 負責 phase 推進與狀態一致性，而不是單純資料轉發 Proxy。

Versioned Telemetry

PLC 對 DCS 使用 cz.plc.dcs.telemetry.v2 契約，DCS 對 SPC 使用另一層版本化契約，避免 PLC、DCS 與 SPC 直接共享內部資料模型。

Auth and Health Design

FastAPI 將一般 API 套用 require_user，internal DCS Router 僅供 Docker Network 串接；health check 區分 livez、readyz 與需登入的 detailed health，避免公開敏感拓撲與 credential。

Deployment Isolation

Docker Compose 包含 postgres、backend、frontend，PostgreSQL 僅綁定 127.0.0.1，backend 僅透過 Docker Network 暴露，並隔離 Compose project 與 network，避免部署 PLC 時影響同主機 DCS 或 SPC。

Engineering Focus

這個專案最適合在面試中展示「工業控制系統邊界」：Plant Simulator 負責製程物理量，Virtual PLC 負責即時掃描、聯鎖、順控與本地控制，DCS 負責操作監督與上層命令，SPC 負責品質分析與判異。

核心價值不是做一個 PLC 儀表板，而是建立 Process Physics → Industrial Protocol → Deterministic PLC Scan → Safety Interlock → Sequence Control → Versioned Telemetry → DCS Supervision → SPC Analytics 的完整、可驗證鏈路。

工程設計上，同一個掃描週期內 UI、DCS 與歷史紀錄看到一致狀態，避免 phase、PV、interlock 與 output 分屬不同時間點，這比單純 WebSocket 即時看板更接近工業控制語境。

後端以 FastAPI 組織 Authentication/RBAC、Registration approval、PLC Runtime、Scan/Sequence/Interlock、OPC UA Plant Adapter、DCS Snapshot Contract 與 Analytics API；資料層以 PostgreSQL 保存 identity、approval 與 audit，以 Parquet/GCS 保存大量製程與研究資料。

此平台是軟體模擬與工程研究用途，不是經認證的 Safety PLC、SIS 或實體設備控制器；在完成獨立安全設計、FAT、SAT 與現場驗證前，不應直接連接真實致動器。
